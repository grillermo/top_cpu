# top_cpu — Timeline Tab Design Spec
Date: 2026-05-05

## Overview

Add a second tab to the top_cpu TUI showing a multi-series CPU usage timeline graph per process. A separate background daemon (`top_cpu --daemon`) records CPU samples to SQLite every 30 seconds. The TUI reads from that database to render historical charts.

## Architecture

### Binary modes

```
top_cpu           → TUI (existing behavior, unchanged)
top_cpu --daemon  → background recorder, no TUI
```

### New files

```
daemon.go   — daemon loop: poll ps → insert SQLite → periodic purge
store.go    — SQLite open/schema/insert/query (modernc.org/sqlite)
```

### Modified files

```
main.go   — detect --daemon flag, branch to daemon or TUI
model.go  — add activeTab, left/right tab switching, timeline sub-model state
```

## Database

**Path:** `~/.local/share/top_cpu/top_cpu.db`
- Directory auto-created on first daemon run.
- Path is hardcoded (no config needed for now).

**Schema:**
```sql
CREATE TABLE IF NOT EXISTS cpu_samples (
    process_name TEXT    NOT NULL,
    cpu_pct      REAL    NOT NULL,
    recorded_at  INTEGER NOT NULL   -- unix seconds
);
CREATE INDEX IF NOT EXISTS idx_recorded_at ON cpu_samples(recorded_at);
```

**Retention:** rows older than 30 days are purged. Purge runs on daemon startup and every hour thereafter via a ticker.

## Daemon (`daemon.go`)

- Poll interval: 30 seconds (reuses `parsePS` from `poller.go`).
- Each tick: run `ps -eo %cpu,pid,args`, parse results, bulk-insert all entries into `cpu_samples`.
- Purge: `DELETE FROM cpu_samples WHERE recorded_at < (now - 30 days)`.
- Graceful shutdown on SIGINT/SIGTERM.
- No output to stdout. Errors logged to stderr.

## Store (`store.go`)

Functions:
- `OpenStore(path string) (*Store, error)` — open/create DB, run migrations
- `(*Store) Insert(entries []rawEntry, at time.Time) error` — bulk insert
- `(*Store) QueryTopN(start, end time.Time, n int) (map[string][]Sample, error)` — top N processes by max CPU in window, bucketed to caller-specified count
- `(*Store) Purge(before time.Time) error` — delete old rows
- `(*Store) Close() error`

`Sample` struct:
```go
type Sample struct {
    BucketStart time.Time
    AvgCPU      float64
}
```

## Tab System

`model` gains:
- `activeTab int` — 0 = list, 1 = timeline
- `timelineState` struct — holds timeline-specific state (time range, chart data, last query time)

**Switching:** `←` / `→` keys switch tabs. Only active when `filtering == false`.

**Header shows active tab:**
```
top_cpu  [▶ List] [  Timeline  ]   excluded: 4
top_cpu  [  List  ] [▶ Timeline]   Range: Today
```

## Timeline Tab

### Time ranges

| Label | Window |
|-------|--------|
| Today | last 24 hours |
| This Week | last 7 days |
| All Time | all rows in DB (up to 30-day retention) |

Cycle with `t` key. Default: **This Week** (shows meaningful data on first open even with a few days of daemon history).

### Keys

| Key | Action |
|-----|--------|
| `←` / `→` | Switch tabs |
| `t` | Cycle time range |
| `r` | Force refresh from DB |
| `q` / Ctrl+C | Quit |

### Data pipeline

1. Query `store.QueryTopN(start, end, 10)` — top 10 processes by `MAX(cpu_pct)` in window.
2. Bucket count = terminal width − 15 (room for Y-axis labels).
3. `QueryTopN` returns one `[]Sample` per process, pre-bucketed and averaged server-side (SQLite `GROUP BY` on time bucket).
4. Log-transform: `y = log10(cpu_pct + 1)` per point — compresses range, handles zeros.
5. Pass to `asciigraph.PlotMany()`.

### Auto-refresh

While on timeline tab, re-query every 60 seconds via `tea.Tick`.

### Chart layout

```
 1.8 ┤ ╭─╮        ╭──╮
 1.2 ┤╭╯ ╰──╮  ╭──╯  ╰╮
 0.6 ┤│     ╰──╯       │
 0.0 ┴──────────────────────
    08:00  12:00  16:00  20:00
Y axis: log₁₀(cpu% + 1)

  ── firefox (89123)   ── node (45211)   ── postgres (1204)
```

- X-axis labels: 4–5 evenly spaced timestamps, format `HH:MM` (today/week) or `MM/DD` (all time). Printed manually below the chart.
- Y-axis: auto-generated by asciigraph from log-transformed values.
- Legend: one entry per process, colored via `asciigraph.SeriesColors`, matching lipgloss color for the name label.

### Empty state

If DB file does not exist or no rows in window:
```
No data. Run: top_cpu --daemon
```

## Error Handling

- DB open failure in TUI → show "DB unavailable" message on timeline tab; list tab unaffected.
- Query error → display error string on timeline tab; retry on next refresh.
- Daemon insert failure → log to stderr, skip tick, continue.
